== 2. Structure des équipes
AppLAB est organisé en modules fonctionnels, chacun supervisé par une équipe dédiée.  
Les mainteneurs assurent : qualité, sécurité, cohérence, revue de code, et conformité Zero‑Trust.

== 10. Processus de validation des Pull Requests
Une PR doit être validée par :
- *1 maintainer du module concerné*  
- *+ 1 reviewer secondaire*  
- *+ @teremuhamblin pour les changements majeurs ou structurels*

Toutes les PR doivent respecter :
- Standards Quantum‑Era  
- Documentation complète  
- Conformité Zero‑Trust  
- Tests et validations internes
